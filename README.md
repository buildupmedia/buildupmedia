## 🛠️ Entwicklung

### Lokale Entwicklung starten

Öffne einfach die `index.html` Datei in einem Browser oder verwende einen lokalen Webserver:

**Mit Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**Mit Node.js (http-server):**
```bash
npx http-server -p 8000
```

**Mit PHP:**
```bash
php -S localhost:8000
```

Dann öffne im Browser: `http://localhost:8000`

### VS Code Live Server

1. Installiere die "Live Server" Extension in VS Code
2. Rechtsklick auf `index.html`
3. Wähle "Open with Live Server"
